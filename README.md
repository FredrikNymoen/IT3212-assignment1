# IT3212 – Assignment 1

This repository contains the preprocessing work for Assignment 1.

## Notebooks

- `notebooks/student_graduation_assignment.ipynb` contains the main analysis.
- `notebooks/food_bank_preprocessing.ipynb` supplements tasks 2 and 3 with missing-value and outlier handling on food-production data.

## Setup

Install the dependencies with:

```bash
pip install -r requirements.txt
```

The datasets are not stored in Git. Download the approved datasets from the course page and place the required CSV files in `data/`. The supplementary Food Bank notebook expects `data/crop1.csv`.
